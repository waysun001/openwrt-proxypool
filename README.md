# OpenWrt ProxyPool

GL-MT6000 定制固件 - 多代理客户端池管理系统

## 功能特性

- **60个代理客户端** - 支持 L2TP 和 SOCKS5 协议
- **内网设备绑定** - 指定IP通过指定客户端上网
- **严格网络隔离** - 未绑定或客户端离线时无法上网
- **LuCI管理界面** - 简易配置，状态监控
- **备份/升级** - 配置导入导出，平滑升级

## 项目结构


## 快速开始

### 云编译

1. Fork 本仓库到你的 GitHub
2. 进入 **Actions** 页面，启用 Workflows
3. 选择编译方式：
   - ⭐ **Build OpenWrt (Fast)** - 推荐，5-10分钟完成
   - Build OpenWrt - 完整编译，2-3小时
4. 点击 **Run workflow** 开始编译
5. 编译完成后下载固件

### 刷机

**从 GL.iNet 原厂固件升级：**
1. 进入 GL-MT6000 管理界面 (192.168.8.1)
2. 系统 → 升级 → 本地升级
3. 上传 `*-factory.bin` 文件
4. 等待重启完成，刷机后管理地址变为 **192.168.9.1**

**从 OpenWrt 升级：**
1. 进入 LuCI 界面 (192.168.9.1)
2. 系统 → 备份/升级 → 刷写新固件
3. 上传 `*-sysupgrade.bin` 文件

## 配置说明

### 添加代理客户端

管理界面: **服务 → 代理池 → 客户端管理**

支持的协议：
- **L2TP** - 需要服务器地址、用户名、密码
- **SOCKS5** - 需要服务器地址、端口，可选认证

### 绑定内网设备

管理界面: **服务 → 代理池 → 设备绑定**

⚠️ **重要规则：**
- 未绑定的设备 → 无法上网
- 已绑定但客户端离线 → 无法上网
- 已绑定且客户端在线 → 通过对应代理上网

### 状态监控

管理界面: **服务 → 代理池 → 状态监控**

- 实时查看所有客户端连接状态
- 流量统计
- 在线设备列表

### 备份/恢复

管理界面: **服务 → 代理池 → 备份升级**

- 导出配置文件
- 升级固件后恢复配置

## 技术架构

- **L2TP**: xl2tpd + ppp
- **SOCKS5**: redsocks + tproxy
- **防火墙**: nftables
- **策略路由**: iproute2
