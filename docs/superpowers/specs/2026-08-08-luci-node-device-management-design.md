# ProxyPool LuCI 中文状态与节点设备管理设计

日期：2026-08-08

## 目标

本次改版提升 ProxyPool LuCI 页面在 40–60 个节点和大量 LAN/WiFi 终端下的可用性：页面状态与错误只显示中文；恢复页面顶部导航；允许从节点列表直接搜索、批量绑定、解除绑定及跨节点迁移设备；节点列表直接展示已绑定设备的局域网信息。

后端 API、运行时状态机和诊断数据继续使用稳定的英文机器码。本次本地化只发生在浏览器展示层，不改变调度、防火墙、故障重试或诊断契约。

## 页面结构

### 顶部导航

ProxyPool 主页面直接加载并渲染包内导航资源，不修改 LuCI 的全局 `header.htm`。导航包含：

- ProxyPool
- 备份与升级
- 无线设置
- 重启

导航使用 LuCI 生成的管理路径，当前页面高亮。导航失效不得阻止 ProxyPool 主页面加载。

### 节点列表

节点列表保留名称、服务器、协议、状态、错误、重试和操作信息，新增“已绑定设备”列及“绑定设备”按钮。

每台已绑定设备在节点行内以紧凑的多行条目显示：

- 设备名称；无名称时显示“未命名设备”
- 当前局域网 IPv4；没有当前地址时显示固定 IPv4
- MAC 地址

一个节点的全部已绑定设备均可在列表中看到，条目允许换行，表格在窄屏上横向滚动。

### 绑定设备弹窗

点击某个节点的“绑定设备”后打开多选弹窗。弹窗具备：

- 按设备名称、当前 IP、固定 IP、MAC、接入方式或当前节点名称实时搜索；
- 每行显示名称、当前 IP、固定 IP、MAC、LAN/WiFi 接入方式；
- 明确显示“未绑定”“已绑定当前节点”或“已绑定：节点名称”；
- 当前节点已有设备默认勾选；
- 取消已有设备的勾选表示解除绑定；
- 勾选其他节点的设备表示迁移到当前节点；
- 未勾选且属于其他节点的设备保持不变。

保存前若存在跨节点迁移，页面列出“设备：原节点 → 当前节点”，并要求二次确认。普通新增绑定和解除绑定不额外确认。

## 中文展示

LuCI 增加集中式展示映射，不在各渲染函数中散落翻译。覆盖：

- 节点状态：已停用、等待连接、正在启动、正在验证、在线、连接不稳定、正在停止、失败、等待重试、正在恢复；
- 后台任务状态：等待执行、执行中、成功、失败、已取消、已替换；
- 诊断状态：尚未生成、等待生成、生成中、可下载、已过期、生成失败；
- 已知运行时与 API 错误，例如认证失败、配置无效、WAN 不可用、连接超时、域名解析失败、连通性检测失败、网络通道建立失败和 DNS 失败；
- 后台任务类型及步骤中当前会直接呈现给用户的机器码。

未知值只显示“未知状态”“未知错误”或“未知任务”，不在普通页面泄露英文机器码。原始值仍保留在 API 响应和脱敏诊断导出中，便于技术排查。

## 批量绑定事务

新增一个受版本号保护的批量设备分配方法。请求只携带发生变化的设备分配：目标节点 ID 表示绑定或迁移，空目标表示解除绑定；单次最多处理 60 台设备。

后端在持有配置写锁时完成以下步骤：

1. 校验请求 ID、配置版本、设备 ID 去重、设备是否存在或已被可信发现、目标节点是否有效；
2. 在配置副本上应用全部分配，计算受影响的原节点与新节点；
3. 对完整结果执行现有配置和安全校验；
4. 仅写入一次配置并只增加一次 revision；
5. 创建一个包含全部受影响节点的后台任务，由现有调度器刷新 DHCP、策略路由和防火墙状态。

任何预提交校验失败时整批不修改。配置提交后的运行时失败沿用现有恢复和 fail-closed 机制，不允许设备临时回退本地 WAN。返回结果包含任务 ID、受影响节点和新 revision，页面沿用轮询展示最终状态。

旧的单设备绑定和解绑 API 保留，以兼容设备页和已有调用方。

## 并发与错误处理

- 弹窗打开时记录当前 revision，保存时携带该 revision；
- 若其他页面已修改配置，后端返回版本冲突，整批不执行，页面提示刷新后重新选择；
- 保存期间禁用搜索、选择和保存按钮，避免重复提交；
- 成功提交后关闭弹窗并立即轮询；
- 失败时保留用户选择，允许重试；
- 页面搜索和渲染不接触或显示节点账号、密码。

## 测试策略

### LuCI 单元测试

- 所有节点、任务、诊断状态与已知错误映射为中文；
- 未知机器码不会直接显示；
- 设备搜索覆盖名称、IP、MAC、入口和节点名称；
- 绑定编辑模型能区分新增、解除、保持不变和跨节点迁移；
- 迁移摘要准确，空变更不提交；
- 节点展示模型包含已绑定设备的名称、IP 和 MAC；
- 导航资源由主页面加载且没有全局模板修改。

### 后端测试

- 多设备新增绑定只增加一次 revision；
- 同一批次可同时解除、绑定和跨节点迁移；
- 受影响节点集合包含全部原节点和新节点且去重；
- 重复设备、未知设备、未知/不可用节点、超过 60 台及过期 revision 均整批拒绝；
- 存储失败不产生部分配置；
- 请求重放返回相同结果，不重复修改；
- 现有单设备 API 行为保持不变。

### 集成验证

- 运行 LuCI Node 测试、Lua 控制器测试、Go 控制器与调度器测试；
- 运行包源安全、IPK 内容和发布契约检查；
- 构建快速软件包并检查版本、架构、依赖、资源加载和文件权限；
- 完整固件仅在软件包检查通过后触发。

## 非目标

- 本次不改变 L2TP 连接、重试或探测算法；
- 本次不启用 SOCKS5/SLP 数据通道；
- 本次不允许手工输入 MAC；
- 本次不改变设备隔离、本地 WAN 禁止、UDP 禁止或管理页面白名单策略。
