# ProxyPool 全局导航、节点流量与备注设计

日期：2026-08-08

## 目标

本次改版解决三个直接影响日常操作的问题：

1. 登录后的所有 LuCI 管理页面均显示 ProxyPool 全局导航，用户从网络、无线、系统等页面都能直接返回 ProxyPool；
2. 节点列表显示本次连接的累计上行/下行流量和实时上行/下行速度；
3. 节点支持中文备注，添加和编辑时可修改，并在节点列表直接显示。

本次不改变 L2TP 建链、探测、重试、设备隔离、本地 WAN 禁止、UDP 禁止和管理页面白名单策略。

## 全局导航

### 选定方案

新增由项目维护的 `luci-theme-proxypool` 主题层。该主题以固件当前使用的 Bootstrap LuCI 主题为基础，拥有自己的主题模板和静态资源，并在定制固件首次启动时将 LuCI 的活动主题设置为 ProxyPool。

不在安装脚本中对其他软件包的 `header.htm` 执行文本替换，也不覆盖 `luci-theme-bootstrap` 所属文件。这样导航行为由版本化的软件包内容决定，不依赖易失效的运行时补丁。

### 展示范围

全局导航显示在登录后的全部 LuCI 管理页面，包括：

- ProxyPool 页面；
- 网络、接口、防火墙和无线页面；
- 系统、软件包、备份升级和重启页面；
- ProxyPool 自己的受限/恢复页面。

登录页不展示管理导航。导航渲染失败不得阻止原有 LuCI 页面和原生菜单加载。

### 导航内容和行为

导航保留清晰的固定入口：

- ProxyPool；
- 网络；
- 无线；
- 系统；
- 备份与升级；
- 重启。

当前页面对应入口高亮。链接由 LuCI URL 生成器产生，兼容管理路径变化。原生 LuCI 菜单继续保留，全局导航只增加快捷返回能力，不隐藏系统功能。

窄屏下导航允许横向滚动或折叠，不能覆盖页面主要操作区。键盘焦点、颜色对比度和触摸区域沿用 LuCI 可访问性要求。

### 安装与恢复

- 完整固件默认包含并启用 ProxyPool 主题；
- 默认配置仅在主题模板和必要静态资源均存在时激活 ProxyPool 主题；
- 软件包热更新只更新主题自身文件，不修改第三方主题；
- 卸载主题前先把活动主题切回 Bootstrap；安装不完整或校验失败时保持 Bootstrap，确保路由器管理页面仍可使用；
- 软件包校验检查主题文件归属、权限、模板语法和禁止修改第三方全局模板的约束。

## 节点本次连接流量

### 统计口径

流量仅统计“本次成功连接”：

- 节点数据通道成功建立并取得接口所有权时，从零开始；
- 同一次连接期间持续累计；
- 断线、失败、人工重连或生成新会话后立即归零；
- 服务重启和路由器重启后归零；
- 不写入闪存，不计入配置 revision，也不随备份恢复。

这一定义优先反映当前节点连接的实际使用情况，同时避免为了流量统计频繁写入闪存。

### 数据来源

后端只读取由 ProxyPool 当前会话拥有的 Linux 网络接口：

- 下行累计：`/sys/class/net/<interface>/statistics/rx_bytes`；
- 上行累计：`/sys/class/net/<interface>/statistics/tx_bytes`。

采集器必须由当前节点 ID、会话 generation 和接口三者共同限定，不能把旧接口或其他节点的流量记入当前节点。

### 采样和速率

- 后端以约 1 秒间隔采样在线节点；
- 首次有效样本只建立基线，速度为零；
- 后续使用字节差值除以真实采样间隔计算 bytes/s；
- LuCI 延用约 3 秒轮询，显示最近一次后端样本；
- 接口暂时不可读、计数器回绕或数值小于上一样本时，不产生负流量，当前速度显示为零并重建基线；
- 节点离线、退避、失败或正在连接时，速度为零，累计值按会话规则保留或归零。

60 个节点时每秒最多读取约 120 个小型 sysfs 文件，不启动外部命令，不解析 `ifconfig`/`ip` 文本。

### 状态接口

节点状态响应增加非敏感字段：

```json
{
  "traffic": {
    "download_bytes": 0,
    "upload_bytes": 0,
    "download_bytes_per_second": 0,
    "upload_bytes_per_second": 0,
    "sampled_at": ""
  }
}
```

计数使用无符号 64 位整数；序列化到 JSON 时保持现有前端可安全处理的数值范围。流量采集失败不得改变节点连接状态，也不得触发重连。

### 页面显示

节点列表新增两个紧凑列：

- 累计流量：两行显示“下行”和“上行”；
- 实时速度：两行显示“下行”和“上行”。

单位自动使用 B、KB、MB、GB、TB 以及 B/s、KB/s、MB/s、GB/s。空值或尚无样本时显示 `0 B` / `0 B/s`，不显示英文机器状态。

## 节点备注

### 数据模型

节点增加可选字段 `note`：

- UTF-8 普通文本；
- 去除首尾空白；
- 最长 200 个 Unicode 字符；
- 禁止控制字符和换行；
- 允许为空。

UCI 节点段使用可选的 `option note` 保存。旧配置没有该字段时按空备注处理，不能因为升级而判定配置无效。

### API 和安全

- `node.save` 接受并验证 `note`；
- 节点公开摘要和脱敏导出包含备注；
- 备注绝不参与命令拼接、接口名、策略 ID、日志标签或连接参数；
- 页面输出使用文本节点/转义，备注中的 HTML 不执行；
- 批量导入格式本次保持不变，导入节点的备注默认为空，避免破坏现有批量导入兼容性。

### 页面交互

添加/编辑节点表单增加“备注”单行输入框，并显示剩余字符提示。节点列表在节点名称下方显示备注；空备注不占额外高度。窄屏和长备注允许换行，但不撑破操作按钮区域。

## 并发与生命周期

流量采集状态只属于运行时内存，由独立组件持有并通过快照读取：

- 调度器在会话成功、结束和 generation 变化时通知采集器；
- 采集器内部串行更新样本，状态 API 只读取不可变快照；
- 删除节点时清除对应运行时样本；
- 编辑备注不会重启节点；
- 编辑会影响连接参数的字段仍沿用现有调度和 revision 机制。

流量状态不得写入 UCI，不得增加配置 revision，不得创建后台任务。

## 测试策略

### 导航和主题

- 主题头部在 ProxyPool、网络、无线和系统代表页面均渲染全局导航；
- 当前入口高亮和 URL 生成正确；
- 窄屏资源和样式可加载；
- 主题软件包不覆盖其他软件包文件；
- 缺失可选资源时原生 LuCI 页面仍能加载。

### 流量采集

- 首次样本建立零基线；
- 正常递增准确计算累计量和速度；
- 不规则采样间隔使用真实时间；
- 计数器回绕、接口消失和重新出现不会产生负数或巨量跳变；
- 相同节点新 generation 归零；
- 旧 generation 的迟到样本被忽略；
- 离线速度归零；
- 60 节点采样不调用外部进程且没有数据竞争；
- 状态接口只暴露非敏感流量字段。

### 备注

- 旧配置无备注可以正常解码；
- 中英文备注保存、读取、编辑和脱敏导出一致；
- 超长、换行和控制字符被拒绝；
- HTML 内容仅作为文本显示；
- 修改备注不触发节点重连；
- 批量导入节点备注为空且旧格式继续可用。

### 集成与发布门禁

- 运行 Go、Lua、LuCI JavaScript、配置 codec 和调度器相关测试；
- 运行 race/并发测试与现有 60 节点压力夹具；
- 构建并检查 core、LuCI 和主题 IPK 的架构、依赖、文件权限与文件归属；
- 软件包工作流全部通过后，才在专用编译服务器执行增量完整固件构建；
- 固件产物验证 SHA256、设备型号唯一匹配和 sysupgrade 元数据后交付。

## 验收标准

1. 登录后进入任意 LuCI 管理页面，页面顶部均能看到并使用 ProxyPool 导航；
2. 在线节点列表可看到本次连接累计上下行流量和实时上下行速度，重连后全部归零；
3. 添加和编辑节点可以保存中文备注，列表立即显示，旧节点不受影响；
4. 以上功能不降低 LAN/WiFi 隔离、fail-closed 和禁止本地 WAN 上网的安全保证；
5. 60 节点情况下页面轮询和后端采集保持可用，不因流量统计引发连接重启或配置写入。
